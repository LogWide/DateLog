# DateLog

DateLog is an iOS application developed as a personal side project to record dates, places, and memories.

## Overview

DateLog helps users manage date schedules and memories through maps, calendars, photos, and notes in a single application.

## Main Features

- 📅 Calendar-based date management
- 🗺️ Map-based place recording (Naver Map SDK)
- 📍 Route and location management
- 📷 Photo attachment
- 📝 Memo & diary
- ❤️ Wishlist management

## Tech Stack

- Swift
- SwiftUI
- SwiftData
- Naver Map SDK
- Git / GitHub
