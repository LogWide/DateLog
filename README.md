# DateLog

DateLog is a personal iOS application developed as a side project to record dates and memories on a map.

## Overview

This project was planned and implemented independently to improve iOS development skills and explore location-based services.

## Main Features

- Date history management
- Map-based location recording
- Calendar view
- Photo and memo management
- Wishlist
- Route and distance information

## Tech Stack

- Swift
- SwiftUI
- SwiftData
- Naver Map SDK
- Git / GitHub

## Status

This project is under active development with new features continuously being added.
